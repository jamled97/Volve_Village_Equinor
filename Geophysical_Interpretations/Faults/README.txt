The directory /project/volvepub/Geophysical_Interpretations/Faults contains one
file with all official faults (fault sticks) for Volve.

File format by character in line:
3-12:	UTMX (meter)
14-24:	UTMY (meter)
26-36: 	TWT (ms)
37-47: 	UNKNOWN (probably 3 columns with color coding)
50:	UNKNOWN
52:	Number on fault stick (1,2,3 for start, middle, end)
53-100:	Fault name
101 and onwards: not relevant.

projected CRS

  type       : UTM
  zone       : UTM Zone 31N
